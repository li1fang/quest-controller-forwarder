# 日常使用：无线采集与录制

最短流程：**头显开机 → 电脑双击 Record-Quest.cmd → 头显打开采集 App → 开始录制 → 停止并保存 → 结束服务并释放保活。**

日常不接电脑 USB、不用 ADB、Meta Link 或 Store PIN，也不用遮挡佩戴感应器。头显与电脑保持在已配对的同一局域网，电脑开着即可。

## 1. 开机并进入预览

1. 头显开机，拿起左右手柄，各按一下扳机或 A/X 键唤醒。
2. 电脑双击项目根目录的 **`Record-Quest.cmd`**，保留启动窗口。它先打开预览，不创建新录制；原 `Start-Quest-LAN-Preview.cmd` 也可继续使用。
3. 临时查看头显，在“应用库 → 未知来源”打开 **Quest LAN Forwarder**；如果出现“继续”等系统确认，确认一次。App 已在运行且网页能收到数据时，无需重新打开。
4. 电脑日常页面为 **http://127.0.0.1:8787/capture**。看到“双手 6DoF 已就绪”后，摘下头显放好，感应器不用遮挡。保持正常光照和追踪摄像头无遮挡。

打开 App 的准备阶段可以佩戴；正式采集时不必佩戴。若显示正在定位，让头显观察明亮房间、双手柄在同一场景轻动，恢复后放回桌上。当前仍需手动开机和打开 App，没有实现冷启动后自动进入采集。

## 2. 开始、停止和再次录制

| 操作 | 点击 | 结果 |
|---|---|---|
| 开始一段 | **开始录制** | 创建独立会话目录，顶部出现“正在录制 · 数据写入本机” |
| 结束这一段 | **停止并保存** | 等待显示“已保存 · 实时预览未录制”，数据完成落盘和校验清单 |
| 再录一段 | **再录一段** | 新建另一个目录，复用在线 App，不用重新佩戴或打开 App |

实时动作本身不会保存；以“正在录制”提示和本次目录为准。上次录制的帧数或“已保存”不代表当前还在录制。停止保存期间不要直接强关进程。

日常使用 `/capture` 页面（`/` 仍兼容），没有默认时间上限或倒计时。录制持续到主动停止、结束服务或存储保护触发。`/test` 单独保留五分钟验收，日常页面不会显示闲置的验收倒计时。

## 长时采集与存储

- 录制栏显示已录时间（向上计时）、原始数据大小、帧数、缺失包和文件目录；等待或放下手柄期间也会保留原始状态。
- 原始文件每 60 秒或达到 32 MiB 后分块，约每秒同步数据和清单。分块不会结束本次录制，也不会重启 App。
- 每 15 秒检查可用空间。低于 512 MiB 时自动停止当前录制并正常保存，原文件不删除；页面会说明原因。预览和保活仍在，全部结束时还需点“结束服务并释放保活”。空间不足时不能新建录制，释放空间后可重试。突发写盘失败仍按失败记录保留最后检查点，不冒充完整保存。
- 没有固定录制时长并不意味着无限电量或磁盘。按上一轮样本估算，原始数据约 0.64 GB/小时，实际随输入内容变化。按动作或批次手动分会话，通常更利于标注。
- 网络中断期间没有设备端缓存；回连后继续保存收到的数据，缺口按实际记录，不补写或伪造姿态。

原来的 **`Start-Quest-LAN.cmd`** 仍保留“启动即录制”行为。如果用它，头显打开前的等待和准备也属于第一段录制；需要准确控制开始时刻时，使用上面的 Preview 入口。

## 3. 全部结束，恢复正常休眠

点击 **结束服务并释放保活**；也可以在启动窗口按 **Ctrl+C** 正常退出。服务会收尾尚未保存的录制、断开头显连接，App 随连接关闭请求撤销模拟佩戴并释放自己的唤醒锁。正常关闭无需 USB、PIN 或手动修改头显设置。

**停止并保存只结束录制，仍保留预览和保活；关闭浏览器标签也不会结束服务。**

释放后恢复头显原有的佩戴检测与休眠策略，不是立即关机；无需手动改回休眠参数，因为本方案没有修改永久休眠设置。实际进入休眠的时间由头显原有策略决定。网络失联但 App 仍正常运行时，租约约十秒后到期并请求恢复；强杀 App 可能跳过清理。若异常退出后仍不正常休眠，可重新启动电脑服务并打开 App，再正常结束服务；仍异常时重启头显。

电脑重新启动采集时，再双击 Preview 入口。头显若已休眠，短按电源唤醒，并按需要重新打开采集 App。

## 数据在哪里

每段位于项目的 `recordings/<UTC时间_UUID>/`，含 `manifest.json`、`raw/*.jsonl`、`events.jsonl`、`annotations.json`。标注单独保存，不改原始姿态。网页会显示具体目录。

已观察到过约 1.91 秒双手输入无效。当前接受这种短暂设备/运行时波动，不列为修复待办；继续保留无效标志，标注或训练时筛选，不把推算结果伪装成有效测量。

## 回放与标注

停止并保存需要标注的这一段后，双击 **Annotate-Quest.cmd**，在 **http://127.0.0.1:8788/annotate** 回放、选取动作区间并保存标签。它默认打开最新的完整录制，使用独立端口，采集页可以继续预览或新建另一段。标注本身不启动采集或保活；全部采集结束后头显可以关闭。详见[标注使用说明](annotation-use.md)。

0.8.1 使用通用 APK。更换电脑 IP 或电脑时，更新并导入配对配置即可，不用重新编译；首次升级和具体步骤见[运行时配对](runtime-pairing.md)。配对完成后正常启动会直接进入采集；需要重新配对时打开独立的 **Quest LAN Pairing** 入口。0.8.1 已验证面板转入采集和结束后恢复休眠；双手有效性及按键复测限制见[验证范围](validation.md)。0.8.0 留在桌面矩形窗口的问题应通过原位更新修复，不需要反复保存配对。
