# 界面与状态约定

工作台面向手柄采集、回放与姿态标注。保留深色空间视图、青色左手 / 紫色右手、轨迹和数值面板，以明确的操作和状态层级整理日常流程。

## 采集

- `/capture` 是日常入口，无默认倒计时。`/test` 是独立五分钟验收入口。
- 录制区固定显示主操作：**开始录制 → 停止并保存 → 再录一段**。停止保存后留在当前页，不打断连续分段采集。
- 已录时长、原始数据量、帧数和目录属于录制统计。双手 6DoF 属于追踪状态；两者分别呈现。保存完成不代表追踪质量通过。
- 仅预览时不会自动写入原始姿态；关闭网页不会停止电脑服务。浏览器连接中断后，录制结果待确认，下方仅为最后收到的统计。
- 软件保活单独显示，技术详情可展开；系统拒绝保活请求时自动展开。**结束服务并释放保活**与停止录制分开。
- 结束服务的电脑回执不等于头显已休眠。App 收到断开或租约到期后请求释放保活，随后由头显的原有策略决定休眠。

## 回放与标注

顶部“回放与标注”说明如何运行 `Annotate-Quest.cmd`。当前仍是独立服务，默认在 8788 端口打开最新完整录制，不会从采集页启动进程，也不会自动选择刚保存的特定会话。指定会话见[标注指南](annotation-use.md)。

标注页使用同一工作台视觉样式，保留三维回放、质量时间轴、I/O 选段、标签编辑及撤销删除。页面始终注明“历史回放 · 非实时”；标签单独保存，原始录制不变。

## 本次范围与验证边界

这次整合采用原界面的视觉风格及流程设计中更统一的状态和操作层级。没有引入新的前端框架、云服务或完整录制库，没有修改设备配对、TLS、采集协议或原始数据格式。

离线回归覆盖录制状态、资源路由、保存/再次录制及标注完整性。浏览器视觉复查受到本机权限设置限制，本次未完成；响应式样式和键盘焦点已编写，但不将其视为浏览器验收。新一轮实机测试后置，历史硬件验证的适用范围见[验证说明](validation.md)。
