# 回放与动作区间标注

双击根目录 **Annotate-Quest.cmd**，打开 **http://127.0.0.1:8787/annotate**。默认载入最新一段已完成、包含姿态帧的录制。头显与手柄可以关闭，采集和保活服务不会启动。

## 操作

1. 播放或拖动进度条寻找动作。支持暂停、上一帧 / 下一帧、0.25× / 0.5× / 1× / 2× 速度；输入“跳到帧”后点“跳转”或回车。
2. 在动作开始处点“设为起点”，在结束处点“设为终点”。也可以直接输入起止帧号，或在表单之外按 I / O。区间包含首尾帧，允许标注单帧。
3. 点“回放选段”核对动作；填写自己的标签，选择左手 / 右手 / 双手，按需要添加备注，再点“保存标注”。等待保存完成提示。
4. 已保存列表支持定位、编辑、删除与撤销删除。刷新或重新启动后仍可读取标签；删除记录保存在同一个标注文件，最新未恢复删除可撤销。

空格播放/暂停，← →逐帧；在输入框中打字时不会触发这些快捷键。当前帧、原始记录号与坐标段会同时显示。

## 数据约定

- 只修改所选会话的 **annotations.json**。原始 `raw/*.jsonl`、`events.jsonl`、`manifest.json` 都不修改。每次保存前重新校验录制完整性。
- 标签引用 `start_sample_id`、`end_sample_id` 和 `coordinate_segment_id`，附原始分块 SHA-256；不能跨坐标段保存一个标签。
- 页面“帧号”仅计姿态帧；原始记录号还包含 status 包。保存时自动映射到真实 sample ID，不能将两者混用。
- 时间轴为相对首个姿态帧的**电脑单调收包时间**，包含录制内的等待间隔；不代表设备与电脑已同步或测得网络延迟。设备采样时间原样保留。
- 颜色区分左右手有效追踪与无效帧。无效姿态隐藏模型，暂停保留选中帧；不插值填补缺失。标签可包含无效帧，但会保留左右手/双手有效帧计数，后续使用时按原始 valid/tracked 标志筛选。
- 标签名称由标注者输入；程序不猜测动作含义，不自动把演示标签写入正式录制。

## 指定会话

```powershell
.\Annotate-Quest.cmd --session "recordings\YOUR_SESSION_DIRECTORY"
# 与采集服务同时运行时选择另一个本地端口
.\Annotate-Quest.cmd --session "recordings\YOUR_SESSION_DIRECTORY" --port 8789
```

结束时点“关闭标注服务”或在终端 Ctrl+C。已保存内容不会丢失，未保存表单需要先保存。默认端口与采集页相同；先结束采集服务再打开标注即可。
